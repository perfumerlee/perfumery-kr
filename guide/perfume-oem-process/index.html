향수 OEM 문의부터 생산까지, 어떤 순서로 진행할까?

처음 제작을 맡기면 무엇부터 정해야 하는지 막막할 수 있습니다. 실제 상담에서는 제품 목적과 수량부터 확인하고, 필요한 항목만 순서대로 결정합니다.

기본 진행 순서

01 상담제품 종류, 수량, 용량, 일정 확인
02 견적향 개발, 생산, 부자재 범위 정리
03 샘플·준비향 개발 또는 생산 사양 확정
04 생산·출고생산 후 최종 확인 및 출고

상담 단계에서 먼저 확인하는 것

판매용 브랜드 향수인지, 굿즈인지, 샘플인지 목적을 먼저 확인합니다. 다음으로 희망 용량과 수량, 향 개발 필요 여부, 출시 일정을 봅니다.

향수 OEM 문의 방법: 먼저 다섯 가지를 알려주세요

처음부터 향과 패키지가 모두 정해져 있을 필요는 없습니다. 아래 정보를 알려주면 제작 가능한 범위와 견적에 필요한 항목을 구분할 수 있습니다.

  1. 제품 목적: 판매용 브랜드 향수, 굿즈, 증정용, PB 중 어느 용도인가요?
  2. 예상 수량과 용량: 예를 들어 30ml 향수 100개인지, 50ml 50개인지 알려주세요.
  3. 향 개발 필요 여부: 기존 향을 사용할지, 레퍼런스를 바탕으로 신규 개발할지 정합니다.
  4. 부자재 준비 상태: 용기·펌프·라벨·단상자를 직접 준비하는지, 조달이 필요한지 확인합니다.
  5. 출시 일정과 예산: 희망 납기와 예산 범위가 있으면 작업 가능 조건을 더 구체적으로 검토할 수 있습니다.
문의 내용 작성 예시 “신규 브랜드 판매용 / 30ml 100개 / 우디 계열 신규 향 개발 희망 / 용기·라벨 미정 / 출시 일정 협의”

위 내용은 작성 예시이며 최소 주문 수량이나 견적을 확정하는 조건은 아닙니다. 상세 사양이 달라지면 생산 가능 여부와 비용도 달라집니다.

향수 OEM 제작 문의하기

견적은 범위를 나눈 뒤 계산합니다.

향 개발비, 생산 공임, 향료와 내용물, 용기, 라벨, 패키지 비용을 구분해 프로젝트에 필요한 범위를 정리합니다.

‘한 병당 생산 공임’에 향료와 용기까지 포함된 것은 아닙니다. 향수 OEM 비용 구성을 먼저 확인하면 같은 견적에서도 어떤 비용이 포함·제외되는지 비교하기 쉽습니다.

생산 전에 사양을 확정합니다.

향, 용량, 용기, 라벨 위치, 포장 방식처럼 실제 생산에 필요한 조건을 확정한 뒤 생산 단계로 넘어갑니다.

자주 묻는 질문

상담 전에 모든 사양이 정해져 있어야 하나요?

아닙니다. 목적, 예상 수량, 예산, 일정 정도만 있어도 상담을 시작할 수 있습니다.

향 개발과 생산을 동시에 진행하나요?

프로젝트에 따라 다르지만 일반적으로 향 방향과 제품 사양을 확인한 뒤 생산 범위를 확정합니다.

견적은 언제 확정되나요?

수량, 용량, 향 개발 여부, 용기와 패키지, 공정 범위가 확인된 뒤 구체적인 견적을 산정합니다.

제작 완료 후 재발주도 가능한가요?

초도 사양과 작업 기록을 기준으로 후속 생산 조건을 협의할 수 있습니다.

다음 단계

처음 향수 OEM을 문의한다면 제품 목적, 예상 수량과 용량, 향 개발 여부, 부자재 준비 상태, 일정부터 알려주세요. 확정되지 않은 항목은 미정으로 남겨도 됩니다.
